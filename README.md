# RentHub - Rental Marketplace Web Platform

RentHub is a full-stack rental marketplace web application that connects users who want to rent products with vendors who want to list their products for rent.

The platform provides multiple rental categories in one place, making it easier for users to browse, view details, and book rental items.

## Features

### User
- User registration and login
- Browse rental items
- View item details
- Search and explore listings
- Book rental items
- View profile
- Authentication using JWT

### Vendor
- Vendor registration and login
- Add rental listings
- Upload listing images
- View own listings
- Update listings
- Delete listings
- Manage bookings

### Admin
- Admin login
- Manage users
- Manage vendors
- Manage listings
- Manage platform data

### Rental Categories
- Cars
- Houses
- Furniture
- Electronics
- Dresses
